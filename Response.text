2xx Success Responses
=================================
200 OK – The request was successful.
201 Created – A new resource has been created successfully.
202 Accepted – The request has been received but not yet acted upon.
203 Non-Authoritative Information – The returned meta-information is not from the origin server.
204 No Content – The request was successful, but there is no content to return.
205 Reset Content – Informs the client to reset the document view.
206 Partial Content – Partial data is returned due to range requests.
207 Multi-Status (WebDAV) – Conveys multiple status codes for multiple operations.
208 Already Reported (WebDAV) – Avoids repeatedly reporting the same resource.
226 IM Used (HTTP Delta encoding) – Indicates a resource was provided via delta encoding.



3xx Redirection Responses
=================================
300 Multiple Choices – Multiple options for the resource.
301 Moved Permanently – The resource has permanently moved to a new URL.
302 Found – Temporary redirection.
303 See Other – The resource is found under a different URL.
304 Not Modified – Indicates the resource has not changed.
305 Use Proxy (Deprecated) – Must be accessed via a proxy.
307 Temporary Redirect – Temporary redirection preserving the request method.
308 Permanent Redirect – Permanent redirection preserving the request method



4xx Client Error Responses
===================================
400 Bad Request – The server cannot process the request due to a client error.
401 Unauthorized – Authentication is required.
402 Payment Required – Reserved for future use.
403 Forbidden – The server refuses to process the request.
404 Not Found – The resource could not be found.
405 Method Not Allowed – The request method is not supported for the resource.
406 Not Acceptable – The requested format is not acceptable.
407 Proxy Authentication Required – Authentication with the proxy is required.
408 Request Timeout – The request took too long to process.
409 Conflict – Indicates a conflict in the request.
410 Gone – The resource is no longer available.
411 Length Required – The Content-Length header is missing.
412 Precondition Failed – Precondition in headers is not met.
413 Payload Too Large – The request payload is too large.
414 URI Too Long – The URI is too long to process.
415 Unsupported Media Type – The media type is not supported.
416 Range Not Satisfiable – The requested range is invalid.
417 Expectation Failed – The Expect header cannot be fulfilled.
418 I'm a teapot – An April Fools' joke response code.
422 Unprocessable Entity (WebDAV) – Validation errors or invalid data.
423 Locked (WebDAV) – Resource is locked.
424 Failed Dependency (WebDAV) – A dependent operation failed.
425 Too Early – Indicates the server is unwilling to process the request at this time.
426 Upgrade Required – The client must upgrade the protocol.
428 Precondition Required – Preconditions are required.
429 Too Many Requests – The user has sent too many requests in a short time.
431 Request Header Fields Too Large – The headers are too large.
451 Unavailable For Legal Reasons – Legal restrictions prevent serving the resource.



5xx Server Error Responses
======================================
500 Internal Server Error – The server encountered an error.
501 Not Implemented – The server does not support the functionality required.
502 Bad Gateway – Invalid response from an upstream server.
503 Service Unavailable – The server is temporarily unavailable.
504 Gateway Timeout – The upstream server did not respond.
505 HTTP Version Not Supported – The HTTP version is unsupported.
506 Variant Also Negotiates – Transparent content negotiation error.
507 Insufficient Storage (WebDAV) – Insufficient storage for the request.
508 Loop Detected (WebDAV) – The server detected an infinite loop.
510 Not Extended – Further extensions are required.
511 Network Authentication Required – Client needs to authenticate for network access.
